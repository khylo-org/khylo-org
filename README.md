<h3 align="center">Your media. Your hardware.</h3>

<p align="center">
  Khylo Server is a free, open-source, self-hosted media server: movies, shows, music, audiobooks, books, comics and live TV
  from your own hardware. No subscriptions, no cloud account, no tracking.
</p>
